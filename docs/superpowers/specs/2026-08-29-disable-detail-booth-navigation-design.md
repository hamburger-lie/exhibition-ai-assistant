# 展商详情页展位按钮禁用跳转设计

## 目标

保留展商详情页“位置与展位”区域中红色展位按钮的现有外观、图标、展位号和按钮元素，但点击或触摸按钮时不再进入展馆地图页面。

## 范围

- 修改 `apps/h5/src/features/entity/EntityDetailPage.tsx` 中展商详情页的展位按钮。
- 保留 `<button type="button">`、现有 CSS 类、定位图标和展位号文本。
- 移除按钮的 `onClick` 跳转逻辑。
- 不删除 `/map` 路由或地图页面。
- 不改变聊天卡片上的其他操作，也不改变产品或活动详情页行为。

## 兼容现有改动

目标文件当前已有“跳转地图时附带展商名称 label”的未提交修改。由于本功能会删除展商详情页的整个地图跳转处理器，该处理器内的 label 参数逻辑也会随之失效；目标文件中的其他现有修改必须保留。

## 测试

先在 `EntityDetailPage` 测试中增加回归用例：渲染带展位的展商详情，确认红色展位按钮仍存在，点击后当前路由不变。测试应在实现前失败，移除点击处理器后通过。

完成后运行目标测试、H5 全量单元测试、类型检查和生产构建，并在部署后的页面上确认按钮显示不变且点击没有反应。

## 发布与回滚

使用新标签构建 H5 镜像，仅替换 Nginx/H5 服务。发布前记录当前镜像 `ai-assistant-h5:20260829-p17`，如验证不通过则恢复该镜像并重启 H5 服务。
